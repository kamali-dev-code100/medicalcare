# MedAI Care — Hospital Management System

![Stack](https://img.shields.io/badge/Stack-MERN-61DAFB?style=flat)
![Realtime](https://img.shields.io/badge/Realtime-Socket.io-010101?style=flat)
![AI](https://img.shields.io/badge/AI-Risk%20Engine-FF6B6B?style=flat)

A full-stack hospital management platform with AI patient risk assessment,
real-time vitals monitoring, and role-based access control.

## Tech Stack

MongoDB · Express · React · Node.js · Socket.io · JWT

```bash

# Frontend
cd frontend && npm install && npm run dev
```
